# Control Total — Android

Prototipo inicial en Kotlin + Jetpack Compose con diseño oscuro azul/morado.

## Incluido
- Inicio con sueldo individual y suma familiar.
- Registro temporal de gastos y deudas con responsable (Familiar, Yo, Esposa).
- Resumen de ingresos, gastos y disponible.
- Workflow GitHub Actions para generar APK debug.

## Importante
Esta es una **versión de demostración**. Los datos se pierden al cerrar la aplicación; todavía no hay Firebase, usuarios, sincronización, cuotas ni historial. No ingresar datos financieros reales.

## Descargar APK
Actions → Android APK → ejecución exitosa → Artifacts → Control-Total-debug-APK.
